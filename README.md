# Barnx Portfolio V2

Production Next.js App Router portfolio for Barnabas Mikel.

## Stack
Next.js 15, React 19, TypeScript, Framer Motion, GSAP/ScrollTrigger, Lenis, Lucide and Zod.

## Routes
- `/` — Home, hero, About scroll story, featured projects, experience, current focus, newsletter
- `/projects` — project archive
- `/projects/[slug]` — full case studies
- `/barnx-studio` — resource ecosystem
- `/barnx-studio/[slug]` — resource details and downloads
- `/Barnabas-Mikel-Resume.pdf` — downloadable résumé

No database, authentication or CMS is included in this phase. Content is data-driven so those can be added later.

```bash
npm install
npm run dev
npm run build
```
