# Barnx Frontend Release Checklist

- Verify mobile, tablet and desktop layouts
- Test keyboard navigation and visible focus states
- Confirm form labels, errors and success states
- Check loading, empty and error states
- Optimize images and fonts
- Review semantic heading order
- Validate metadata, Open Graph, robots and sitemap
- Test all internal and external links
- Run Lighthouse and fix meaningful regressions
- Respect prefers-reduced-motion
